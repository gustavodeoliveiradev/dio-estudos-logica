## 📌 Sobre este repositório

Este repositório documenta minha jornada de **revisão completa de Lógica de Programação** através da plataforma [DIO](https://dio.me).

Já havia concluído esta formação anteriormente, mas decidi **refazer do zero** como parte do meu compromisso de estudar "igual gente grande" — com disciplina, prática e documentação rigorosa.

> 💡 Refazer a base não é retroceder — é **fortalecer os alicerces** para construir coisas maiores.

## 🎯 Por que refazer a base?

> *"Conheço devs que usam React há 5 anos e não sabem explicar a diferença entre `==` e `===`."*

Este repositório é meu compromisso com:

- ✅ **Clareza conceitual** — entender o *porquê* antes do *como*
- ✅ **Prática deliberada** — resolver problemas, não apenas assistir aulas
- ✅ **Documentação do aprendizado** — registrar para revisitar e compartilhar
- ✅ **Mentalidade de melhoria contínua** — sempre há algo novo para aprender
